# Gimao On-Device (Gimao 设备端私有云)

[![License](https://shields.io)](LICENSE)
[![Platform](https://shields.io)](https://www.gimao.space)


**Gimao On-Device** 是一款革命性的 Android 端本地私有云平台。它致力于**一键将优质的开源服务（如 Memos、相册、看板、云存储等）直接移植并运行在 Android 手机或平板等设备上**。无需命令行、无需远程服务器、无需公网 IP，让每个普通用户都能零门槛享受开源技术的自由与安全，实现 **100% 的本地数据掌控**。



---

## 🎯 项目核心特性

- **🚀 零门槛一键运行**：彻底摆脱复杂的 CLI（命令行）操作，内置服务器一键触控启动。
- **🔒 100% 本地安全**：所有数据纯本地存储，不经过任何第三方云端，无账户注册体系，从源头杜绝隐私泄露。
- **🌐 离线优先 & 局域网同步**：完全支持无网离线工作，并提供安全的本地局域网（LAN）同步功能。
- **📂 聚合开源生态**：
  - **GimaoMemos**：支持 Markdown 实时预览、灵活的标签系统与全文本搜索的随手记功能。
  - **本地文件及相册管理**：内置文件管理器，支持图片与多媒体附件的本地安全存储与随笔记管理。
- **⚡ 高效的数据导出**：随时随地一键打包导出全部个人数据，真正掌握数字主权。

---

## 🛠️ 环境与运行要求

### 设备要求
- **操作系统**：Android 8.0 (API Level 26) 及以上
- **架构支持**：`arm64-v8a`, `armeabi-v7a`, `x86_64`
- **存储空间**：建议留有至少 500MB 可用空间（视本地数据存储量而定）


---



### 方案 A：直接安装使用 (推荐)
前往 [Gimao 官网](https://www.gimao.space) 或 在仓库内直接下载安装。

## 🏗️ 项目架构与流程

```text
+-----------------------------------------------------------+

|                      Gimao Android UI                      |
+-----------------------------+-----------------------------+
                              | 一键唤醒 / API 交互
                              v
+-----------------------------------------------------------+

|                  Gimao On-Device Core                     |
|           (嵌入式本地服务器引擎 & 容器化环境)             |
+-----------------------------+-----------------------------+
                              |
      +-----------------------+-----------------------+

      | 本地存储 (100% Local) | 局域网同步 (LAN Sync) |
      v                       v                       v
[SQLite / NDK File DB]     [Markdown 附件]      [WiFi 局域网节点]
```

1. **启动流程**：用户打开 App 点击“启动” -> 核心层在 Android 独立沙盒内拉起嵌入式开源服务环境。
2. **数据流向**：用户所有的输入、笔记和媒体文件通过应用直接写入 Android 本地受保护的存储区，不进行任何云端传输。
